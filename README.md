# WatchBus

WatchBus показывает ближайшие остановки наземного транспорта Москвы на Pebble Time 2. Проверенная связка — Pebble Time 2 и Pixel 10 с Android.

## Использование

- При запуске часы показывают площадки в радиусе 1 км по расстоянию от телефона. Подсказка «Далее» помогает различать одноимённые остановки.
- Прогнозы подгружаются для пяти ближайших площадок и для новых площадок по мере прокрутки. Под остановкой появляются до двух ближайших прибытий.
- **Select** открывает полное табло. В нём прибытия сгруппированы по маршруту и, когда направление известно, по следующей остановке. Иконки различают автобус, электробус и трамвай. Пометки «прогноз» и «по расп.» показывают источник времени.
- **Select** на табло запрашивает обновление, **Back** возвращает к выбранной площадке. Чтобы заново определить геопозицию, выбери «Обновить» в списке.

## Сборка и установка

Нужны [Pebble SDK и CLI](https://developer.rebble.io/sdk/) с поддержкой платформы `emery`, а также Node.js для тестов.

```sh
node --test tests/*.test.js
pebble build
```

Готовый пакет — `build/WatchBus.pbw`. Открой его на телефоне через приложение Pebble, установи WatchBus на часы и разреши доступ к геолокации и сети.

Для проверки в эмуляторе можно задать координаты около «Пехотной улицы».

```sh
pebble install --emulator emery
pebble emu-set-location --emulator emery 55.810687 37.482877
pebble install --emulator emery
pebble logs --emulator emery
```

## Данные и каталог остановок

Телефон ищет остановки локально по `src/pkjs/catalog.json`. Живые прогнозы приходят из `stop_v2` сервиса «Московский транспорт», а плановые времена — из [городского расписания](https://transport.mos.ru/transport/schedule). Публичные квоты и условия стороннего доступа к живым табло пока неизвестны. При HTTP 429 приложение учитывает `Retry-After`, если сервер его прислал.

Каталог входит в исходники, поэтому обычная сборка использует готовые данные. Для обновления каталога нужны Python 3, curl и доступ к городским сервисам. Команда ниже создаёт кэш ответов во временной папке.

```sh
catalog_cache="$(mktemp -d)"
python3 scripts/build_catalog.py --cache "$catalog_cache" --output src/pkjs/catalog.json
```

Проверь итоговое число площадок и список `unresolved` в каталоге. Для повторного прогона можно указать тот же каталог кэша. Для получения свежих ответов используй новый кэш.

## Версии и релизы

WatchBus использует [SemVer](https://semver.org/). Версия в `package.json` совпадает с версией пакета, а Git-тег и релиз на GitHub получают префикс `v`.

- **MAJOR** — несовместимое изменение документированного поведения или поддерживаемой платформы.
- **MINOR** — новая обратно совместимая возможность.
- **PATCH** — обратно совместимое исправление.

Перед публикацией запусти тесты и собери `WatchBus.pbw` из коммита релиза. Опубликуй пакет в [GitHub Releases](https://github.com/G0-G4/WatchBus/releases) с тегом этого коммита. Изменения уже опубликованной сборки выпускай под новой версией.
